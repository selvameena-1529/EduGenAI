# EduGenAI - AI-Powered Educational Content Generator

## Overview
EduGenAI is an AI-driven platform that automatically generates high-quality educational content like quizzes, summaries, flashcards using NLP and Machine Learning.

## Features
- Auto Quiz Generation
- Summarization
- Flashcards
- Personalized Learning Path

## Tech Stack
- Python, NLP, Machine Learning
- Flask / FastAPI
- GitHub

## How to Run
1. Clone repo: git clone https://github.com/selvameena-1529/EduGenAI.git
2. Install: pip install -r requirements.txt
3. Run: python app.py
